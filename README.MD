## 📺 Lien de la Playlist

Vous pouvez ajouter directement le lien suivant dans votre application IPTV favorite :

```text
https://raw.githubusercontent.com/ZeroxarZ/iptv-fr/main/playlist_fr.m3u8
```

> [!TIP]
> En utilisant l'URL directe ci-dessus dans votre lecteur, votre liste de chaînes se mettra à jour automatiquement à chaque actualisation du dépôt !

## 📖 Guide d'installation rapide

### 1. Sur VLC Media Player (Ordinateur)
1. Ouvrez **VLC**.
2. Allez dans le menu **Média** (en haut à gauche) > **Ouvrir un flux réseau...** (ou `Ctrl + N` sous Windows / `Cmd + N` sous macOS).
3. Collez l'URL de la playlist :
   ```text
   https://raw.githubusercontent.com/ZeroxarZ/iptv-fr/main/playlist_fr.m3u8
   ```
4. Cliquez sur **Lire**.
5. Appuyez sur `Ctrl + L` pour afficher la liste de lecture et choisir votre chaîne.

### 2. Sur TiviMate / IPTV Smarters / OTT Navigator (Android & TV)
1. Ouvrez l'application.
2. Choisissez **Ajouter une playlist** (ou *Add Playlist*).
3. Sélectionnez le type **M3U Playlist / URL**.
4. Saisissez un nom (ex: `IPTV France`) et collez l'URL directe.
5. Validez et profitez du guide et des flux.

### 3. Sur Kodi (Extension PVR IPTV Simple Client)
1. Allez dans **Paramètres** > **Extensions** > **Installer depuis un dépôt**.
2. Sélectionnez **Clients PVR** > **PVR IPTV Simple Client** > Installer.
3. Configurez l'extension : dans l'onglet **Général**, définissez l'emplacement sur *Chemin distant (URL Internet)* et insérez l'URL de la playlist.

## 🤝 Contribution

Les contributions sont grandement appréciées ! Vous pouvez participer au projet pour :
- 🔗 Ajouter une nouvelle chaîne gratuite et légale.
- 🛠️ Signaler ou corriger un lien de flux obsolète / cassé.
- 🎨 Améliorer les logos (`tvg-logo`) ou métadonnées (`group-title`, `tvg-id`).

### Comment contribuer ?
1. **Forkez** ce dépôt.
2. Créez une branche dédiée : `git checkout -b feature/nouvelle-chaine`
3. Effectuez vos modifications dans [`playlist_fr.m3u8`](./playlist_fr.m3u8).
4. Commitez vos changements : `git commit -m "Ajout du flux X"`
5. Poussez sur votre branche : `git push origin feature/nouvelle-chaine`
6. Ouvrez une **Pull Request**.

## ⚖️ Avertissement légal / Disclaimer

> [!IMPORTANT]
> **Ce dépôt ne propose et n'héberge aucun flux payant, piraté ou soumis à un accès conditionnel restreint.**
>
> - Toutes les chaînes référencées dans cette playlist sont des flux **libres d'accès**, **gratuits** et **diffusés publiquement** par leurs diffuseurs respectifs ou distributeurs autorisés sur Internet.
> - Ce projet se contente d'indexer et d'organiser des liens hypertextes déjà publics (m3u8 / HLS).
> - Si vous êtes titulaire des droits d'un flux et souhaitez son retrait de cette liste, veuillez ouvrir une [Issue GitHub](https://github.com/ZeroxarZ/iptv-fr/issues) et le flux sera supprimé immédiatement.
